EMİR: GRUNGE RUN — PC (Windows) sürüm 2.1
=========================================
EmirGrungeRun.exe dosyasına çift tıkla. Kurulum gerekmez, tek dosya.
Windows "bilinmeyen yayıncı / SmartScreen" uyarısı verirse: "Ek bilgi" > "Yine de çalıştır".

5 dünya × 10 bölüm, dünya haritası, patronlar, dünya müzikleri.
PC'de 3D görüntü 3 kat çözünürlükte (768x576) ve 60 FPS çizilir.
Kayıt: %APPDATA%\EmirGrungeRun\save.dat

KLAVYE
  Oklar / WASD   yürü          Z / Boşluk   zıpla (basılı tut: yüksek)
  X / Shift      koş, ateş, taşı   C          dönerek zıpla / süzül
  ↓              eğil, havada yere çakıl
  Q / E          haritada dünya değiştir
  Enter / Esc    duraklat      Geri (Backspace)  duraklatınca haritaya dön
  M              müzik aç/kapa F11 / Alt+Enter   tam ekran

KONTROLCÜ (Xbox ve uyumlular, PlayStation)
  Sol çubuk / D-pad yürü · A (Çarpı) zıpla · B / X (Kare/Daire) / tetikler koş
  Y (Üçgen) dön · LB / RB haritada dünya · Start duraklat · Back/Share müzik
